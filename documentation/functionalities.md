# Functionalities

- User can create an account
- User can login
- User can logout
- User can create a trip
- Trip owner can add locations to the trip (country, city, background color, notes, accommondation and dates)
- Trip owner can edit and remove locations
- Trip owner edit trip details (title, background image and budget)
- Trip owner can add other users as travellers and choose their role (editor or reader)
- Trip owner can delete their trip
- Trip owner can download their trip as PDF file
- Trip editor can do everything that the owner can, except delete the trip or edit the trips travellers
- Trip reader can only view and download the trip
- User can see all their trips in their home page
- User can search and filter their trips
